# SevaHub design system

SevaHub is a two-sided local-services marketplace. Preserve the product's existing single-page dashboard model: warm amber/orange actions, soft gray canvas, white rounded cards, compact bold headings, dark outline/shadow accents, and responsive grid layout. Keep system sans-serif typography and the established utility-like card/button/pill components.

For this update, design only the workflow additions: user booking detail state for a pending worker counter-offer, an accepted booking state with a private customer TPIN, worker booking cards that never reveal a TPIN but show a completion PIN input when eligible, and a dedicated user AI Assistant area with conversation history, a message composer, typing indicator, and graceful error state. Use clear human labels: Pending, Bargaining, Waiting for your response, Accepted, Rejected, In progress, Completed. Keep the existing navigation and do not redesign unrelated dashboard areas.
